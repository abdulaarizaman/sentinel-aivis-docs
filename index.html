01 / INTRODUCTION

What is SENTINEL AIVIS?

SENTINEL AIVIS explores how different technologies can work together to make an access-control demonstration more interactive and intelligent.

Project concept

The prototype combines an ultrasonic sensor for approach detection, a laptop-hosted AI engine for identity checks, and an Arduino-controlled model gate for demonstrating an access decision.

System approach

The laptop acts as the main processing unit. Python handles AI-related tasks, a Node.js application supports monitoring, a database stores registered identity records, and Arduino manages physical model components.

Name expansion: AIVIS stands for Artificial Intelligence and Voice-Integrated Sight. The name reflects the project's combination of visual recognition and voice interaction.
02 / PROJECT FOUNDATION

Objectives & scope

The project is designed to demonstrate the integration of AI software, electronics and a physical access-control model.

◎

Approach detection

Detect an approaching object or visitor using an ultrasonic distance sensor.

◉

⌘

Automated response

Send a decision to the Arduino controller to demonstrate the gate response and status display.

03 / WORKING PRINCIPLE

How the system works

The prototype follows a sequence of detection, identity checks, decision handling and a model-gate response.

01
Approach detectionUltrasonic sensor detects a nearby object or visitor.
02
Voice interactionThe system prompts for a registered spoken ID or credential.
03
Face checkThe camera and AI engine perform the configured visual identity check.
04
DecisionThe application evaluates the verification result and status.
05
Gate responseArduino controls the model servo gate and display status.
Important: This is a demonstration workflow. A successful software result should not be treated as proof of real-world identity or as authorization for a real door or facility.

07 / INTELLIGENT FEATURES

AI & identity verification

The project demonstrates two different identity-related inputs: a spoken credential and a visual face-recognition process.

Voice interaction

The voice module listens for a spoken ID or configured credential and passes the captured input to the verification workflow. Audio quality, background noise and speech-recognition accuracy can affect results.

Face recognition

The webcam supplies visual input to the Python computer-vision module. The configured recognition system compares the detected face with enrolled reference data.

Privacy note: Face images, voice recordings and identity records are sensitive personal data. Obtain informed permission before collecting or demonstrating them, limit access, and avoid publishing real people's biometric data in this documentation.

09 / TRANSPARENCY

Limitations & safety

Clear limitations make technical documentation more credible. This project is an educational prototype, not a certified security product.

Current prototype considerations

!
Recognition reliabilityLighting, camera quality, noise and environmental conditions can affect recognition.
!
Hardware constraintsModel-scale components and power arrangements are not equivalent to industrial access hardware.
!
Network dependencyDatabase and hosted-service availability can affect connected features.
!
Security validationThe prototype has not been independently audited or certified for real-world security use.

Responsible demonstration

Use only consenting participants and test records. Do not connect this exhibition prototype to a real building entrance, emergency exit or critical security system.

Keep credentials private, secure database access, and avoid sharing API keys, tokens, private repository links or personal identity data in public screenshots.

Any real deployment would require professional engineering, threat modelling, privacy review, fail-safe design, independent testing and compliance with applicable laws.

12 / HELP

Frequently asked questions

Quick answers to common questions about the project.

What does AIVIS stand for?

AIVIS stands for Artificial Intelligence and Voice-Integrated Sight.

What is the main processing unit?

The laptop acts as the main processing unit, running the Python AI engine and the Node.js monitoring application.

What is the role of Arduino UNO?

Arduino UNO handles the connected electronics, including the servo-driven model gate and display-related control.

Why are voice and face checks included?

They demonstrate two different identity-related inputs—spoken credentials and visual recognition—as part of the project's learning objective.

Can SENTINEL AIVIS be used to secure a real building?

No. The current project is an educational prototype and is not certified, independently audited or suitable for controlling real-world access.

Where can I try the visitor portal?

The project's visitor portal is available at aivis-v.onrender.com. Availability depends on the hosting service.
